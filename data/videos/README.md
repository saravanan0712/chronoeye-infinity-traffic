# ChronoEye Infinity Video Storage Directory

Place your traffic video files (.mp4, .avi, .mov, .mkv) in this directory for offline analysis and benchmarking.

Example:
  data/videos/traffic_sample_01.mp4

To process a video file using the Stage 1-3 pipeline:
  python run_video_detection.py --source data/videos/traffic_sample_01.mp4
